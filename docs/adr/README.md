# Architecture Decision Records

This directory contains the Architecture Decision Records (ADRs)
that document significant architectural and technical decisions
for the RP2350 Secure OTA System.

## Decision Records

| ID | Title | Status |
|---|---|---|
| ADR-001 | Boot Strategy using RP2350 Secure Boot and Stage 2 OTA Bootloader | Accepted |

## ADR Conventions

Each ADR should document:

- **Context:** The problem, constraints, and relevant technical background.
- **Decision:** The selected approach and its rationale.
- **Alternatives:** Other approaches considered and why they were rejected.
- **Consequences:** Benefits, trade-offs, and implementation implications.
- **Status:** Proposed, Accepted, Deprecated, or Superseded.

ADRs are maintained as individual Markdown documents to preserve
their history, traceability, and reviewability.
